# HOSTING.md

**Unwarranted.** Nothing in this project is deployed anywhere: there is no
server, no hosted service and no coordinator image to run in one. The
coordinator installs onto a developer's machine, which is installation,
not hosting — the installer, the artefacts and rollback live in
[`RELEASE.md`](RELEASE.md). This file exists only to state that, per
`plan.md` §7's table. Revisit it if something hosted ever appears.
